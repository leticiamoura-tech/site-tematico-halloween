# 🎃 Site Temático de Halloween

## 📌 Sobre o projeto

Este projeto consiste em um site temático de Halloween, desenvolvido como atividade prática para aprimorar conhecimentos em desenvolvimento web.

O objetivo é apresentar uma página com identidade visual inspirada no Halloween.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome

## 📂 Estrutura do projeto

- css/: arquivos de estilização.
- fontawesome/: biblioteca de ícones.
- img/: imagens utilizadas no site.
- js/: arquivos JavaScript.
- index.html: página principal.

## 🚀 Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo index.html no navegador.
